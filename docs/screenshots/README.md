# Screenshots

Drop PNGs here with these exact filenames and the placeholders in the main
README resolve automatically. Once a file exists, replace the corresponding
`> _Screenshot: ..._` line in `README.md` with:

```markdown
![Alt text](./docs/screenshots/library.png)
```

| Filename | What to capture |
|---|---|
| `library.png` | The library grid with a decent number of thumbnails loaded. Widen the window first — the grid looks best with 5+ columns. |
| `cull.png` | The culling view on a strong frame, with the filmstrip visible along the bottom and a star rating applied so the overlay shows. |
| `develop.png` | The develop module on a photo that clearly benefits from editing. Sidebar expanded, histogram visible. This is the hero shot — pick the best image. |
| `tone-mapping.png` | The develop sidebar scrolled to the Tone Mapping section with GT selected, so its four shape sliders are showing. |
| `masks.png` | A radial mask placed on a face or subject, rotated off-axis, with its handles and the sidebar's mask adjustments visible. |
| `copy-settings.png` | The Copy Settings dialog open with a partial selection ticked. |
| `performance-hud.png` | <kbd>F3</kbd> HUD while dragging a slider, so the frame graph has activity in it rather than sitting flat. |

## Notes

- Capture at a consistent window size so the images sit together well — around
  1600×1000 is a good target.
- Prefer your own photographs; these end up in a public README.
- PNG rather than JPEG: the UI is flat colour and text, which JPEG smears.
